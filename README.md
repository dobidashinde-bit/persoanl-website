Personal Portfolio Website

A simple, clean, and minimal personal portfolio website built with HTML, CSS, and JavaScript.

The website showcases my projects, coding interests, GitHub profile, and personal information with a simple hand-drawn arrow animation.

✨ Features
Clean and minimal design
Responsive layout for desktop and mobile
Animated PNG arrows around the Blog and GitHub buttons
Personal introduction section
Project showcase with 3 projects
Direct link to the Wordle project
GitHub profile link
Simple CSS animations
Google Fonts integration
🛠️ Built With
HTML5 — Website structure
CSS3 — Styling, layout, and animations
JavaScript — Arrow animation timing and interactions
Google Fonts — Typography
